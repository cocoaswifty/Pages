## Publishing

Enable GitHub Pages for this repository from the `main` branch and root folder.

The public URL is built from:

- `url` in `_config.yml`: `https://cocoaswifty.github.io`
- `baseurl` in `_config.yml`: `/Pages`
- each page's `permalink`

For example, `V2EX/privacy-policy.md` uses `permalink: /V2EX/privacy-policy/`, so the final URL is:

`https://cocoaswifty.github.io/Pages/V2EX/privacy-policy/`
