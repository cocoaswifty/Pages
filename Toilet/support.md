# Toilet Support

Need help with Toilet? Contact support:

cocoaswifty@gmail.com

Please include:

- Your device model
- iOS version
- Toilet app version
- The area, toilet listing, or feature involved
- A short description of the issue

## Correcting a Toilet Listing

If you find inaccurate toilet information, use the edit feature in the app and submit the proposed correction. New, edited, and deletion submissions are placed in an administrator review queue. The public toilet directory is updated only after an administrator approves the submission. While a submission is pending, the submitting device may show a local preview of the proposed change.

## 更正公廁資料

如果你發現公廁資料有誤，請直接在 App 內編輯並提交修改內容。新增、修改與刪除資料都會先進入管理員審核清單，管理員核准後才會更新公開的公廁資料。審核期間，提交修改的裝置可能會先顯示該修改的本機預覽。
